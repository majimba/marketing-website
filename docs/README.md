# Luminary Co. Website

A modern, single-page marketing website for Luminary Co., a Lusaka-based creative and media agency. Built with HTML, Tailwind CSS, and vanilla JavaScript for optimal performance and maintainability.

## 🚀 Quick Start

1. **Clone or download** this repository
2. **Open** `public/index.html` in your browser
3. **Deploy** to any static hosting provider (Netlify, Vercel, GitHub Pages)

## 📋 Project Overview

This website serves as the primary digital storefront for Luminary Co., designed to:
- Communicate the company's mission and unique value proposition
- Showcase world-class services and portfolio work
- Generate qualified inbound leads from prospective clients and talent
- Establish brand positioning as a leading creative powerhouse in Africa

## 🎯 Target Audience

- **Corporate & NGO Leaders:** Decision-makers seeking strategic creative partnerships
- **Musicians & Creators:** Artists and influencers looking for professional brand management
- **Potential Talent:** Creatives and strategists interested in joining the company

## 📱 Features

### Core Sections
- **Hero:** High-impact introduction with "Your Story, Amplified." tagline
- **About Us:** Brand narrative and mission statement
- **Founders:** Meet the visionary team behind Luminary Co.
- **Services:** Six core service offerings in a clean grid layout
- **Portfolio:** Visual showcase of key projects with hover effects
- **Why Choose Us:** Competitive advantages and value propositions
- **Testimonials:** Rotating client quotes for social proof
- **Movement:** Call-to-action for partnership opportunities
- **Contact:** Lead capture form with direct contact information

### Interactive Elements
- Sticky navigation header with backdrop blur
- Mobile-responsive hamburger menu
- Smooth scroll animations using Intersection Observer API
- Testimonial slider with automatic cycling and manual navigation
- Hover effects on portfolio items and service cards
- Animated background patterns and fade-in effects
