# Open Graph Images

This directory contains social media sharing images for the website.

## Required Images

### Current Status
- ❌ `team-1200x630.png` - **NEEDED**: Open Graph image for the Team page

### Image Requirements
- **Dimensions**: 1200×630px (Facebook/Twitter optimal size)
- **Format**: PNG or JPG
- **Content**: Should include:
  - "Meet the Team" title
  - Luminary Co. branding
  - Visual representation of team concept
  - Golden yellow (#ffc75b) accent color
- **File Size**: Keep under 1MB for optimal loading

### Design Guidelines
- Use the existing brand colors: black background, golden yellow accents
- Include the Luminary Co. logo
- Make text readable at small sizes
- Consider the image will be cropped on different platforms

### Usage
This image is referenced in the team page meta tags:
```html
<meta property="og:image" content="https://luminaryco.co/assets/og/team-1200x630.png">
```
