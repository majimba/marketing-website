# Assets Folder Structure

This folder contains all visual assets for the Luminary Co. website during development and production phases.

## 📁 Folder Organization

### `/images/hero/`
- **Hero background video/image** (1920x1080)
- Main landing page visual
- **Priority:** HIGH - First impression asset

### `/images/about/`
- **Team photo** (600x400)
- Company culture and team representation
- **Priority:** HIGH - Builds trust

### `/images/services/`
- **Service showcase images** (optional)
- Visual representations of each service offering
- **Priority:** MEDIUM - Enhances service descriptions

### `/images/portfolio/`
- **Project showcase images** (600x400 each)
- 6+ portfolio project visuals
- **Priority:** HIGH - Proof of work

### `/images/testimonials/`
- **Client avatar images** (circular, 200x200)
- Professional headshots for testimonials
- **Priority:** MEDIUM - Adds credibility

### `/images/contact/`
- **Office/location image** (optional)
- Company workspace or Lusaka location
- **Priority:** LOW - Enhancement only

### `/icons/`
- **Service icons** (64x64 or 128x128)
- 6 service category icons
- **Priority:** MEDIUM - Visual organization

### `/placeholders/`
- **Development placeholder images**
- Temporary images during development
- **Priority:** LOW - Development only

## 🎨 Asset Specifications

### **Image Formats:**
- **Hero:** JPG/PNG (1920x1080) or MP4 (video)
- **Portfolio:** JPG/PNG (600x400)
- **Team:** JPG/PNG (600x400)
- **Icons:** PNG with transparency (64x64 or 128x128)
- **Avatars:** JPG/PNG (200x200, circular crop)

### **Color Palette:**
- **Primary:** #ffc75b (Luminary Gold)
- **Secondary:** #000000 (Black)
- **Accent:** #ffffff (White)
- **Background:** #1a1a1a (Dark Gray)

### **Style Guidelines:**
- Modern, professional, creative
- Premium feel and quality
- Culturally relevant to Africa
- Consistent brand aesthetic

## 🔄 Update Process

1. **Generate AI assets** → Place in appropriate folders
2. **Update HTML** → Replace placeholder URLs with local asset paths
3. **Test website** → Ensure all assets load correctly
4. **Replace with production** → Swap AI assets for real content
5. **Optimize** → Compress and optimize final assets

---

**Note:** During development, use AI-generated assets to create a professional appearance. Replace with authentic content before final deployment.
