# Why Choose Us Images

This folder contains images for the "Why Choose Us" section on the home page.

## Image Requirements

- **Size**: Recommended 64x64px (16x16 in Tailwind) to match service card images
- **Format**: PNG, JPEG, or JPG
- **Style**: Should represent each "Why Choose Us" point visually

## Current Points (3 cards):

1. **A Strategy That Wins Today** - `strategy.png` (or .jpg/.jpeg)
   - Represents strategic thinking, planning, or modern approach

2. **Production That Moves People** - `production.png` (or .jpg/.jpeg)
   - Represents creative production, film, photography, or artistic work

3. **A Partner You Can Trust** - `trust.png` (or .jpg/.jpeg)
   - Represents partnership, trust, handshake, or collaboration

## Usage

These images will be displayed in 64x64px cards above each "Why Choose Us" point, similar to the service cards in the "What We Do" section.

## Styling

Images will be styled with:
- `w-16 h-16` (64x64px)
- `object-cover rounded-lg` for consistent appearance
- Centered above each text point
